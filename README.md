## 📋 项目概览

本项目为 **2025 年全国大学生电子设计竞赛 E 题「简易自行瞄准装置」** 的完整实现。
装置由自动寻迹小车 + 瞄准模块两部分组成：小车沿 100cm×100cm 方形轨迹自动寻迹行驶，
瞄准模块以二维云台控制蓝紫激光，使光斑在行驶过程中持续命中靶心。

**本项目身份与完成度说明：**

| 项目 | 状态 |
|---|---|
| 基本要求(1) 自动寻迹 N=1~5 圈 | ✅ 已实现（圈数可设定） |
| 基本要求(2)(3) 静态瞄准 | ✅ 已实现 |
| 发挥(1) 单圈动态追踪 D₁≤2cm | ✅ 已实现 |
| 发挥(2) N=2 圈动态追踪 D₁≤2cm | ✅ 已实现 |

| **移动追踪最大误差位置** | 直角转弯处，误差控制在 **三环（半径 6cm）内** |
| **功能代码分布** | **核心视觉与追踪算法主要位于 K230 端** |

## 🏗️ 系统架构

采用 **「K230 负责『看 + 算』，MSPM0 负责『控 + 转发』」** 的分工设计，
两芯片通过自定义串口协议实时协作：

```
┌────────────────────┐         UART (AA BB X Y CC)         ┌─────────────────────┐
│   K230 视觉端       │  ───────────────────────────────►  │   MSPM0G3507 主控   │
│                    │   下发: 云台 X/Y 轴 RPM 速度      │                     │
│  · Canny矩形识别    │                                    │  · 12路灰度循迹     │
│  · 动态ROI + 滤波  │                                    │  · 多环PID控制      │
│  · 目标追踪 + PID   │  ◄──────────────────────────────  │  · 陀螺仪圈数判定   │
│  · 激光控制         │     反馈/控制 (步进电机驱动)       │  · 总线步进电机云台  │
└────────────────────┘                                    └─────────────────────┘
         ▲                                                        │
         │ 传感器: 摄像头(800x480 / 320x240)                        ▼
                                                                 云台 (X/Y 双轴)
```

- **K230 端（算法核心）**：全屏矩形识别 + 云台激光闭环控制
- **MSPM0 端（执行核心）**：循迹、电机、步进云台驱动、通信协议

## 🧠 技术亮点

### 1. 视觉识别与目标追踪（K230 端）
- **Canny 边缘检测矩形识别**，配合 `cv_lite` 边缘 AI 推理，实时锁定靶框
- **多目标得分筛选**：综合目标面积、帧间位移、面积突变率打分，抗多目标干扰
- **动态 ROI 搜索**：以上一帧目标为中心动态调整搜索窗口，丢线时逐步扩大，兼顾性能与可靠性
- **EMA 指数平滑 + 帧间防跳变验证**：抑制识别抖动与误锁定，实现在直角转弯等剧烈运动下的稳定追踪
- **掉帧惯性滑行**：丢失目标后按衰减系数维持云台速度，平滑过渡，避免激光跳动

### 2. 云台激光闭环控制（K230 端）
- 自定义 `PID` 类，Yaw/Pitch 双轴独立控制，带积分限幅与输出限幅
- 60fps 级实时解算，将像素误差映射为云台 RPM 指令

### 3. 自动寻迹与底盘控制（MSPM0 端）
- **12 路灰度传感器阵列**加权平均求线偏差
- **三次非线性平滑函数**代替分段阶跃，消除直道画龙与弯道抽搐
- **丢线盲区补偿**：卡灯缝自动滑行、边缘飞出即时激发表、持续脱轨强制纠偏
- **多环 PID 体系**：速度环 / 转向环 / 距离环 / 角速度环 / 角度环，`PID_Calculate` 位置式统一计算
- **基于陀螺仪累计偏航**的圈数判定状态机，终点前预判减速平稳越线

### 4. 自定义串口协议
- K230 → MSPM0：`AA BB X_L X_H Y_L Y_H CC`（int16 小端速度帧），含 20ms 发送限速与速度死区过滤
- MSPM0 → 总线步进电机：正点原子 SMD 伺服协议完整解析（位置/速度/力矩/电流环 PID 等数十个功能码）
- **200ms 超时保护**：K230 断链自动云台停机，保证安全

### 5. 工程调优能力
- 基于实测数据反复迭代 PID 参数（详见 [`PID_Tuning_Record.md`](PID_Tuning_Record.md)）
- 总线步进电机内部 PID / 电流 / 加速度固件级调参（Kp/Ki/Kd、堵转电流、避共振）

## 📥 本地导入（MSPM0 工程）

1. 安装 [Code Composer Studio](https://www.ti.com/tool/CCSTUDIO) 12.x 及 [MSPM0-SDK](https://www.ti.com/tool/MSPM0-SDK)
2. `File → Import → C/C++ → CCS Projects`
3. 选择本仓库目录，导入后编译烧录

K230 端代码可直接部署到 K230 开发板运行，接线见代码注释。
